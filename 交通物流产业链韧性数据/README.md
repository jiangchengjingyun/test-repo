## 二、数据规模

- 样本：99 家 A 股交通运输与公路桥梁板块上市公司 × 2015—2023 年 = **891 个企业—年度观测**，与论文完全一致。
- 名单取自新浪财经行业分类（交通运输 87 家、公路桥梁 20 家，共 107 家），剔除 8 家年度不全者（退市、被吸收合并）。
- 板块构成：物流服务型 726 个观测、基础设施型 165 个；东部地区占 74.7%。

## 四、口径要点

- **数据要素水平 DEL**：无形资产占比、研发投入强度、数字资本开支强度三维度，极差标准化后熵值法赋权（0.288/0.470/0.241），再合成。
- **产业链韧性 RES**：抵抗能力（盈利稳定性、现金流保障、成本控制）与恢复能力（行业调整增长、资产周转、冗余资源）各自熵权合成后等权平均；负向指标反向处理。
- **缩尾**：连续变量 1%/99% 分位缩尾。研发费用 2018 年前多数公司未单列，按 0 处理并保留 `rd_missing` 标记。
- **工具变量 IV**：公路密度、货运量、人均GDP、城镇化率 Z 值等权平均。

## 五、复现精度

熵权与论文表1、表2高度一致（恢复维度 0.144/0.533/0.323，论文 0.134/0.534/0.332）；数据要素水平均值由 2015 年 0.064 升至 2020 年 0.129，与论文图2 走势吻合。基准回归 DEL 系数 -0.0536（论文 -0.0500），恢复能力 -0.1464（论文 -0.1104），IV 估计 0.769（论文 0.744），方向、显著性与量级均可对应。逐项对照见 `07_核心结果对照`。

## 六、使用方式

Stata：

```stata
use "交通物流_企业面板.dta", clear
encode stkcd, gen(id)
xtset id year
xtreg RES DEL Size Lev Growth Roa i.year, fe vce(cluster id)
```

或直接运行 `复现_基准回归.do`（工作目录设为本文件夹）。Excel 亦可 `import excel ..., sheet("01_分析面板") firstrow` 直接导入，已实测通过。
